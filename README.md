# AI-6-Months-Journey 🚀

مرحباً بك في المستودع الخاص برحلتي لاحتراف الذكاء الاصطناعي وهندسة البرمجيات في 6 أشهر.

## 📅 سجل التقدم (Progress Log):

* **Day 1:** أساسيات بايثون (المتغيرات، الأنواع، والشروط الأساسية).
* **Day 2:** التحكم في المسارات والمنطق البرمجي (If-Else Statements).
* **Day 3:** التعامل مع القوائم (Lists)، الحلقات التكرارية (Loops)، وإدارة المخزون.
* **Day 4:** بناء الدوال (Functions)، تمرير المدخلات (Parameters)، واستخدام الـ Return لبناء أنظمة قابلة لإعادة الاستخدام.
* **Day 5:** استخدام القواميس (Dictionaries)، ربط البيانات (Key-Value Pairs)، وبناء أنظمة حساب الفواتير وتطبيق الخصومات المعقدة.
* **Day 6:** البرمجة كائنية التوجه (OOP)، بناء الفئات (Classes)، الكائنات (Objects)، واستخدام دالة `__init__` لتعريف هياكل الأنظمة.
* **Day 7:** التعامل مع الملفات (File I/O)، أوضاع القراءة والكتابة (Read/Write/Append)، وتصفية البيانات باستخدام الـ Context Managers.
* **🏆 Milestone 1 (Day 7):** بناء مشروع تخرج مصغر (Smart Store) يدمج المتغيرات، الدوال، القواميس، البرمجة الكائنية (OOP)، والتعامل الدائم مع الملفات (File Handling).
* **Day 8:** استخدام المكتبات القياسية (Standard Libraries) مثل `os` و `datetime`، وبناء واستدعاء وحدات مخصصة (Custom Modules) لتنظيم الكود.
* **Day 9:** استخدام مدير الحزم (PIP) لتحميل مكتبات خارجية (`requests`)، الاتصال بواجهات برمجة التطبيقات (APIs) لجلب بيانات حية من الإنترنت (مراقب سعر البيتكوين اللحظي)، وتطبيق معالجة الأخطاء المتقدمة (Error Handling)
  
سأستمر في التحديث يومياً! 💪
